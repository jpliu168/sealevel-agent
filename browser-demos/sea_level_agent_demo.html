What is an AI agent? A sea-level example

An agent is a language model placed inside a harness: a loop that lets it call skills (tools and packaged know-how), see the results, and decide what to do next. Below is a working sea-level agent built on NOAA CO-OPS tide gauges. Ask it about any coastal place and it finds the gauge, fetches the data, plots it, and writes a summary.

The three pieces

The same pattern sits behind Claude, ChatGPT agents, and research assistants in general. Here's what each part does in a geoscience setting.

Harness

The program around the model. It runs the loop: pass the question in, run whatever tool the model asks for, feed the result back, and stop when the job is done. It also enforces limits such as allowed websites, permissions, and time budgets.

e.g. Claude Code / Cowork, or a 100-line Python loop around an LLM API

Agent (the model)

The reasoning step. It reads the request, plans, chooses which skill to call with which arguments, interprets the output, and recovers when a step fails, for example by trying the next-nearest gauge.

"Norfolk → nearest NOAA gauge is Sewells Point (8638610). Get 2016–2025 monthly means."

Skills & tools

Reusable capabilities. Some are tools (call an API, run code). Others are skills: a written recipe of domain know-how, such as "remove the seasonal cycle before fitting a trend, and report the 95% CI."

geocode · find_nearest_station · fetch_monthly_mean · trend_analysis · plot · summarize

Under the hood: the agent is a set of files

The harness (this page) loads these files when you run Claude mode. Edit one in the meastest folder, reload, and the agent changes, with no code changes. AGENTS.md is the agent's standing instructions. Each SKILL.md is a recipe; Claude sees only the name and one-line description until it decides a skill fits and calls load_skill. tools.json lists the tools Claude may call; their code lives in the harness.






  
Two brains, one harness

  
Scripted rules runs anywhere without an API key. It parses questions with fixed rules and does not read the files above, so unusual phrasings and follow-up questions break it. That's the point of the comparison.

  
Claude reads AGENTS.md, picks a skill, loads it, and decides which tools to call and in what order. It keeps the conversation, so you can ask follow-ups and "why" questions.

  
Data modes. Run locally (start_demo.command), the page calls NOAA live, so any US gauge works. When hosted where outside calls are blocked, it uses built-in NOAA data for 2016–2025 at 27 gauges plus NOAA's long-term trends for 144 gauges.
