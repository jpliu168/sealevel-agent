# Sea-level report

1. Gather results with the other skills (place trends, long-term trends,
   explanation, any plots).
2. Write `outputs/report_<place>_<date>.md` with:
   - title, date, data source line;
   - **Key numbers**: a small table (gauge, id, distance, period, trend ± CI,
     long-term trend);
   - **What the data show** (3–5 sentences) with the figure(s) embedded by
     relative path;
   - **Why** (2–4 bullets, causes labeled as data-supported or general
     knowledge);
   - **Caveats** and **Data sources** (NOAA CO-OPS station pages:
     https://tidesandcurrents.noaa.gov/stationhome.html?id=<id>).
3. Keep it to one page. Tell the user the file path.
